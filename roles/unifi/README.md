# UniFi Controller

Deploys the [UniFi Network Controller](https://ui.com/) via rootless Podman using the [`jacobalberty/unifi`](https://github.com/jacobalberty/unifi-docker) image (embedded MongoDB, no external DB required).

Variables: [defaults/main.yml](defaults/main.yml)

## Firewall ports

Opened in UFW for `unifi_firewall_allowed_sources`:

| Port | Protocol | Purpose |
|---|---|---|
| 8080 | TCP | Device inform |
| 8443 | TCP | Web UI |
| 3478 | UDP | STUN |
| 10001 | UDP | AP discovery |

## AP adoption

APs on the same L2 network discover the controller automatically via port 10001/udp. For L3 adoption, configure the AP inform URL: `http://<unifi_bind_address>:8080/inform`.

## Nginx Reverse Proxy

Set `unifi_nginx_enabled: true` and `unifi_nginx_hostname` to expose the web UI over HTTPS (requires the `nginx` role). The vhost proxies to the controller's own HTTPS port, `unifi_bind_address:8443` (self-signed, not verified by nginx). TLS is opt-in:

- `unifi_nginx_letsencrypt: false` (default) — use the shared self-signed cert (`nginx_default_ssl_cert`, generated by the `nginx` role). Required for internal names like `*.nas.local`, which Let's Encrypt cannot issue.
- `unifi_nginx_letsencrypt: true` — provision a Let's Encrypt cert via the shared `nginx` role's certbot tasks. Requires a publicly-resolvable hostname with a DNS record pointing at the host.
